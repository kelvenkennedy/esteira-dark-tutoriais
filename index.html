03 / Instalação no Windows

Comece com o jeito fácil

Se você usa Codex ou outro assistente com acesso permitido aos arquivos do seu computador, copie o texto abaixo para orientar a instalação. Esse processo não substitui um instalador próprio.

Instalação assistida

Sou iniciante e comprei a Esteira Dark. Ajude-me a instalar e testar o sistema no Windows.
1. Peça para eu selecionar a pasta do produto que recebi por meio do meu acesso privado.
2. Faça backup antes de alterar qualquer arquivo.
3. Verifique Python, FFmpeg, ffprobe, Ollama, Piper e faster-whisper. Liste o que falta.
4. Mostre o que pretende instalar e peça autorização antes de executar instalações.
5. Configure os arquivos locais sem divulgar senhas, tokens ou endereços privados.
6. Teste o sistema usando um vídeo que eu tenha autorização para utilizar.
7. Mostre onde encontrar o vídeo final e registre os erros, se houver.
Não afirme que tudo funciona sem executar os testes.

Instalação manual (avançada)

Baixe primeiro as ferramentas nos sites oficiais:

Python · FFmpeg · Ollama

Confirme que os comandos python --version, ffmpeg -version e ollama list funcionam no terminal. A configuração completa depende da versão adquirida.

06 / Dúvidas

Precisa de ajuda?

O Ollama não responde. O que fazer?

Confira se o programa está instalado e em execução. Teste ollama list no computador e não exponha a porta da IA à internet.

O sistema não encontra o FFmpeg.

Confira a instalação, a variável PATH e execute ffmpeg -version e ffprobe -version.

Posso usar cenas de filmes?

O produto não inclui licença sobre obras de terceiros. Trabalhe com mídia autorizada e respeite as regras de cada plataforma.

Posso acessar a IA por este site?

Ainda não. O backend autenticado e os planos pagos precisam ser implementados para liberar esse acesso com segurança.
